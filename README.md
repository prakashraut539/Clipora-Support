# Clipora Clipboard for Windows

Clipora is a free Windows x64 clipboard manager, available on Microsoft Store. Search copied text, links and images with Ctrl+Alt+V, keep useful clips pinned, and paste into your active field. History is encrypted locally by default.

[Get Clipora from Microsoft Store](https://apps.microsoft.com/detail/9NN5TJ6G4T5W?cid=clipora-github)

## Report a bug or suggest a feature

Open an issue with your Windows version, Clipora version, synthetic reproduction steps and expected/actual behavior. Issues are public. Never post real clipboard history, passwords, access tokens, encryption keys or private paths. Review screenshots before attaching them.

Windows may restrict automatic paste into elevated applications; copy and manual Ctrl+V remain available. Back up your history before resetting or uninstalling the Store app. File clips contain references, not file contents.
